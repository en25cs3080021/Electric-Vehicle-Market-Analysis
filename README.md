# Electric Vehicle Market Performance Analysis

## Project Overview
This project analyzes the Electric Vehicle (EV) market using Tableau Public. It provides insights into EV sales trends, vehicle types, manufacturers, state-wise performance, average vehicle prices, and charging types.

## Live Interactive Dashboard
[Click Here to View Tableau Dashboard](https://public.tableau.com/app/profile/zoya.naaz.sheikh/viz/Electricvehicle1/ElectricVehicleMarketPerformanceInsights)

## Key Insights
- Monthly EV sales trends from 2022 to 2025.
- EV sales comparison by vehicle type.
- State-wise EV sales performance.
- Manufacturer-wise EV sales analysis.
- Average EV price comparison by manufacturer.
- EV sales by charging type.
